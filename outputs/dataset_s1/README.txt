Dataset S1. Main figure data and reported manuscript values

This dataset provides the tabular values used to generate the main manuscript figures and the headline values reported in the text for "Hypsographic Demography Revisited: Age Structure and Population Change by Elevation."

Files

1. dataset_s1_key_manuscript_values.csv
   Key values reported in the manuscript text, including global low-elevation population totals and shares, population-weighted median elevation, highland population totals, youth shares, and growth comparisons.

2. dataset_s1_fig01_population_age_growth.csv
   Source data for Fig. 1A and Fig. 1B, including population by elevation group, year, and broad age group, plus age composition and growth summaries.

3. dataset_s1_fig01_age_contributions.csv
   Source data for Fig. 1C. Age-class contributions are calculated as each broad age group's 2015-2025 population change divided by total 2015 population in the corresponding elevation group, so contributions sum to total growth.

4. dataset_s1_fig01_elevation_threshold_summary.csv
   Source data for the total-population cumulative elevation profile in Fig. 1D, including population below or equal to selected elevation thresholds.

5. dataset_s1_fig01_elevation_threshold_age_summary.csv
   Source data for age-specific cumulative elevation profiles in Fig. 1D and age-specific threshold values reported in the manuscript.

6. dataset_s1_fig01_elevation_threshold_region_summary.csv
   Regional cumulative elevation threshold summaries, including the Asia below-150-m value reported in the manuscript.

7. dataset_s1_fig02_settlement_static2025.csv
   Source data for Fig. 2A-C, including population, youth share, and growth by elevation group and 2025 GHS-SMOD settlement class.

Notes

- Elevation groups are <100 m, 100-499 m, 500-1,499 m, 1,500-2,499 m, 2,500-3,499 m, and >=3,500 m.
- Threshold files summarize population below or equal to the listed threshold value.
- Broad age groups are 0-14, 15-64, and 65+.
- Settlement classes are descriptive groups based on the 2025 GHS-SMOD Degree of Urbanisation layer.
- Values are derived from modeled gridded population estimates and should be interpreted as aggregate modeled patterns.
